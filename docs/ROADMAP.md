## V0.1：Android Gacha URL Import PoC

目标：最小界面证明手机独立链路。Shared Core 从开始就建立，不等 V0.3 再抽离。

| 任务 | 依赖 | 完成证据 |
| --- | --- | --- |
| Android 壳与受限 IPC | 构建基线决策 | APK 安装、启动、权限/网络记录 |
| CredentialSource / URL parser | 可信格式与 host 证据 | 合成正常及恶意输入测试、无原文日志 |
| Credential 验证与身份 | API-05 及渠道来源 | B服角色和 server 确认；歧义不合并 |
| Character / Weapon Provider | 已确认接口契约 | 角色分页、武器池列表、武器分页 |
| SyncEngine 与 Storage | 唯一性与 schema 审查 | 幂等写入、失败恢复基础、事务检查点 |
| 手机端最小联调 | 上述全部 | 无 PC 完成授权→同步→重启读历史 |

验收全部必须达成：

- [ ] Android APK 正常安装运行。
- [ ] 可主动粘贴完整链接，自动识别格式并解析必要字段。
- [ ] parser 和网络错误不泄漏 Token；默认仅本次授权。
- [ ] 可在线判断授权是否有效，识别或明确拒绝歧义角色归属。
- [ ] 角色寻访、分页、武器池和武器寻访可用。
- [ ] SQLite 保存成功，重复导入不重复，App 重启历史仍在。
- [ ] 全过程无需 PC，不依赖 Windows 导出。

V0.1 已包含 SQLite/分页/去重的最小验证，V0.2 是完善可靠性而不是把这些基础验收推迟。UI 不要求成熟，统计与复杂图表不阻塞 PoC。

## V0.2：Android Complete Gacha Client

完善多账号/角色管理、角色与武器全量和增量、类型校验、限流退避、取消、离线、过期、部分失败、分页循环、恢复和迁移。可选持久化授权必须先验证安全存储；没有此项仍保留 session-only 完整路径。

验收：错误不损坏历史，多角色不串数据，重复同步幂等，进程回收后可重新授权继续，真实样本的唯一范围得到记录。根据 Phase 0 结果加入必要的手机独立后备授权方式。

## V0.3：Android Analytics 与 UI

AnalyticsEngine / Rules 独立于 Vue；基础统计、时间线、月统计、各池/星级、六星间隔、UP、ECharts、明暗与触摸布局。规则有版本/证据，缺失历史显示不确定性，平均/中位不混入截断周期。

## V0.4：Windows Full Client

复用 Domain、Provider、SyncEngine、Analytics、Schema、Types、Rules、Credential parser；新增 Windows 安全存储、文件/回调适配、桌面布局与便利登录。验收 Windows only 独立可用，核心同一套规则。

## V0.5：WebDAV

显式启用、无授权快照、跨端 UUID 映射、双向集合合并、冲突检测、条件发布、损坏恢复。Android 与 Windows 不互为前置条件。

## V0.6：其他工具 Import / Export

bhaoo、RoLingG、EndCat 格式及 JSON/CSV/XLSX；先按优先样本逐个适配。预览、身份确认、去重、冲突和事务；不复制未经许可的导入器。

## V0.7：PWA

轻量查看、离线缓存、分析、历史导入及可选 WebDAV 拉取；验证 CORS 与浏览器存储限制，不承担核心游戏登录。

## V0.8：报告与分享

年度报告、分享图、欧非分析。公共百分位仅在有合适样本且用户 opt-in 时提供；默认不上传 UID、设备信息或完整历史。

## 当前十大技术风险

1. Android B服当前版本无法取得完整 URL。
2. URL 授权过短、单次或只适用于某池，无法完整同步。
3. 授权有效但渠道/角色不能可靠解析。
4. seqId 唯一范围、排序或分页边界与猜测不同。
5. API 或游戏 WebView 更新改变格式和鉴权。
6. Android 进程回收、安全存储或系统备份破坏授权边界。
7. 上游 UI/Token 耦合增加迁移成本，构建方案不适合 Mobile。
8. 不完整历史、免费抽和继承规则导致统计误导。
9. 多端并发写、旧工具格式或身份映射导致冲突/重复/漏数。
10. 根许可证与具体文件/依赖/游戏素材的许可边界不同。

每项风险的关闭证据进入对应主题文档；排期不以“已经找到开源代码”代替验证。
