# 授权与输入安全

状态：必须满足的设计要求，尚未实现。

## 授权边界

密码永不由应用持久化。游戏 Token、Cookie、OAuth/refresh/U8 凭据、完整寻访 URL 不进入普通日志、错误事件、截图、遥测、SQLite 业务库、Git 或 WebDAV。调用相应官方鉴权/游戏接口所必需的凭据传输不等于上传到本产品云端；不得转发给统计、诊断或同步服务。

V0.1 默认“仅同步本次，不保存授权”。凭据在核心内存中持有；同步结束或取消即释放，不写状态恢复包。应用退出后用户可以重新提供链接，SQLite 历史保留。尽量缩短秘密副本寿命，不能声称托管语言内存绝对可擦除。

持久化授权为后续显式选择。Windows 系统凭据库、Android Keystore 保护的存储、Stronghold 或等价方案需实际验证密钥来源、解锁、重启、备份和卸载行为；Keystore 不能被简单视为任意 Token 文件库。禁止自制加密和硬编码密钥。业务库至多保存 credential_ref、类型、期限等非秘密元数据。

## Gacha URL 输入

- 输入页使用隐藏/遮罩的粘贴控件，解析后立即清空原文显示。普通 UI/store 只保留脱敏摘要；不展示完整 Token、Cookie、Authorization。
- 剪贴板仅由用户点击“从剪贴板粘贴”触发；不轮询、不后台读取、不将原文发送到分析服务。不擅自覆盖用户剪贴板。
- 输入长度、参数数和值长度有限制，具体阈值在 parser 实现时定义并测试。使用标准 URL parser，不用手写正则承担完整解析。
- 仅接受经 [API_RESEARCH](API_RESEARCH.md) 登记准入的精确 HTTPS host/端口/路径；检查规范化后的 hostname，拒绝 userinfo、伪装子域名、任意端口、javascript/file/intent 等协议。
- 拒绝语义冲突的重复参数、异常编码、嵌套 URL、未经批准的 fragment 参数；不得反复解码以“修复”恶意输入。未知非敏感参数是否忽略需格式契约明确。
- **绝不 fetch 用户粘贴的地址。** 提取参数后交由 Provider 构造固定可信 API 请求。重定向默认不跟随，或逐跳验证目的 host；绝不携带凭据跨到非批准域名。
- `token`、`u8_token` 等映射必须来自格式证据；不同 Token 类型不能仅靠长度判断。解析成功不表示在线有效。

## 运行时与日志

游戏 API URL 可能通过 query 携带秘密；禁止记录完整请求 URL。HTTP 调试器、错误链、崩溃报告、IPC、Pinia 持久化及自动状态恢复均纳入脱敏范围。以白名单输出 operation、状态码、脱敏测试编号及耗时，禁止序列化整个请求/响应对象。

raw_json 只保留用于重解析的脱敏记录 payload，丢弃授权响应、Header、URL、Cookie 和其他不必要个人字段。诊断样本优先合成；真实样本须脱敏并检查嵌套结构、错误信息及附件。

UI 用“授权无效，请重新获取链接”表达已确认无效；只有已确认过期时才说“寻访授权已过期，请重新复制最新寻访链接”。超时、断网、限流不能误报过期，更不能自动删除历史。

## 存储、导入、同步

SQLite 本地存储不自动等于加密，不能宣传设备被攻破后仍绝对保密。限制应用文件访问；Android 系统备份排除授权和秘密缓存。退出登录清除该授权，不默认删除寻访历史。

导入 JSON/CSV/XLSX 限制文件大小、层数、记录数量和压缩展开量；不执行宏或外部引用。格式识别先验证再预览、事务写入。发现凭据字段应拒绝/剥离并告知，不能随历史数据入库。

WebDAV 使用安全保存的独立同步凭据，不包含任何游戏凭据；使用 HTTPS 并保留证书验证。同步仅显式白名单业务字段；UID 和历史属于用户数据，不称为匿名。schema、校验和、冲突与启用流程见 [SYNC](SYNC.md)。

## Git 与发布

`.gitignore` 排除环境文件、真实数据库及 WAL/SHM、userData、Cookie/Token dump、抓包、鉴权 debug 日志和真实 API 响应。忽略规则不能替代内容审查。fixture 必须合成或彻底脱敏；游戏素材和第三方源码分别登记许可。

公共统计与遥测默认关闭，另行 opt-in；未来运气百分位不得隐式上传 UID、设备信息或完整历史。可选 WebDAV 授权不等于同意公共统计。

## 必需验证

parser 恶意 host/scheme/重复参数/异常编码；授权失效与离线区分；错误日志无原文；导入恶意字段；raw_json 无秘密；WebDAV 快照无凭据；取消/重启无授权残留；多账号切换不会复用错误凭据。测试仅用合成秘密标记，不使用真实 Token。
