# Android 完整客户端

Android 是首要平台，所有主流程按无 PC 用户设计。V0.1 是 URL Import PoC，基础统计在 V0.3；完整排期见 [ROADMAP](ROADMAP.md)。

2026-09-02 环境检查：Node/Java/adb 可运行，但 adb 无设备；未发现 Rust 与 Android SDK/NDK 可用配置。当前未构建 APK，细节及无秘密设备记录表见 [ANDROID_VERIFICATION](ANDROID_VERIFICATION.md)。

## V0.1 用户流程

“添加寻访数据”首先显示“粘贴寻访链接”，其次手动授权、官方网页登录、其他工具历史导入。未实现路径明确标为计划，不展示可用按钮误导用户。只有 URL 路线 VERIFIED 后，才能添加“推荐 · 无需在本应用重新登录”的正式宣传。

主动粘贴 → 格式/host 检查 → 脱敏摘要 → 在线验证 → 服务器/渠道/角色识别 → 确认同步 → 角色与武器分页 → 本地保存 → 查看历史。渠道可显示 Unknown；角色待识别时不能误写既有账号。输入安全见 [SECURITY](SECURITY.md)。

V0.1 只需安装、输入、进度、结果和历史页面；不做复杂 Dashboard。随后首页优先展示同步入口、当前垫抽、最近六星、总抽数、平均六星、最后同步时间和历史。统计需标明不完整数据和未知规则。

## 生命周期与界面

通过 Rust 共享核心进行请求、去重和存储，不把逻辑嵌入 Android 页面。数据库检查点允许中断恢复；进程被杀后可以重新提供凭据重放页面，不因丢失内存 Token 丢弃已有记录。

V0.1 不承诺长期后台同步；明确展示正在同步/已暂停/需重新授权，避免系统冻结后仍显示成功。网络权限遵循最小范围，不申请读取游戏私有目录作为核心路线。

支持触摸目标、窄屏、系统字体缩放、明暗主题、安全区域和输入法；保存成功后离线可读。首次导入确认页只显示必要的脱敏信息。复杂图表按需加载。

## 最大 blocker 与切换条件

首要 blocker 是手机能否获得稳定有效的 B服授权 URL，而不是图表或桌面壳。源码有 Windows 日志取链接功能不能消除它。若 URL 路线 FAILED/不稳定，先评估手机独立手动授权，再提升官方网页登录；不能以“先用电脑导出”完成手机验收。

Windows 在 V0.4 复用已验证核心，只补平台适配、桌面交互及便利授权功能。PWA 在 V0.7 读取业务快照/导入历史，支持离线查看和分析；浏览器 WebDAV CORS 与存储限制另行验证，不复制原生凭据访问权限。
